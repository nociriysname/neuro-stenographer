# Методика и результаты тестирования

> Результатов пока нет: модели не подключены. Ниже — методика, по которой будем мерить.

## Метрики (как у организаторов)

| Метрика | Что меряет | Инструмент |
|---|---|---|
| WER | ошибки распознавания слов | `jiwer`, нормализация как у организаторов (уточняется) |
| DER | ошибки диаризации: пропуск, ложная речь, путаница спикеров | `pyannote.metrics` |
| Ошибка границ | среднее отклонение `start_ms` / `end_ms` реплик | свой скрипт |
| RTF | время обработки / длительность записи | тайминги из `ProcessingTimings` |

## Тестовый набор

- Русские диалоги 2–4 человек: свои записи в разных условиях (тихо, шум, перебивания) и открытые корпуса.
- Эталон для каждого файла — JSON в формате ТЗ.

## Порядок прогона

1. Собрать release APK, поставить на тестовое устройство.
2. Прогнать набор в пакетном режиме, получить JSON и тайминги.
3. Посчитать метрики, записать строку на файл в [`artifacts/test-results/results.csv`](../artifacts/test-results/results.csv).
